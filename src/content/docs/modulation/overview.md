The **Modulators** panel holds Aconite's movement generators, reached through a
scrolling tab strip: six drawable **LFOs**, the **step sequencer**, the
**Performer** curve sequencer, the **bus LFOs**, and the **envelope follower**.
Each is a source you can route in the modulation matrix to make a patch move.
