---
title: Tutorials — learn by doing
description: End-to-end walkthroughs that build whole patches and teach a subsystem in context.
---

The reference chapters explain each control; the tutorials put them together. Each
walkthrough builds a complete patch from scratch and teaches a subsystem along the
way. Planned tutorials include a fat analog bass, an evolving pad, a 303 acid line
(filter, accent, and slide), a physical-modeled pluck (String / Modal), a kick
(Kick oscillator), a multitimbral split (scenes), and wiring your first modulation
(the matrix and right-click Modulate).
